# PlantCare - Помощник садовода

Полнофункциональное десктопное приложение на Python для управления растениями, созданное на основе веб-версии PlantCare.

## 🌿 Особенности

### Основные функции:
- **🔐 Аутентификация пользователей**: Регистрация и вход в систему
- **🏠 Дашборд**: Главная страница с задачами и советами по уходу
- **🔍 Каталог растений**: Поиск и фильтрация растений по сложности и освещению
- **🌿 Мои растения**: Управление личной коллекцией растений
- **👤 Профиль пользователя**: Настройки аккаунта и управление данными
- **🌙 Тёмная тема**: Переключение между светлой и тёмной темой
- **📥📤 Экспорт/импорт данных**: Сохранение и восстановление данных пользователя
- **📋 Задачи**: Автоматическое создание задач по уходу (полив, удобрение)
- **💡 Советы**: Полезные советы по уходу за растениями

## 📋 Требования

- Python 3.8 или выше
- Windows, macOS или Linux

## 🚀 Установка

1. Склонируйте или скачайте репозиторий:
```bash
cd plantcare_app
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python main.py
```

## 📖 Использование

### Первый запуск

1. При первом запуске нажмите "Зарегистрироваться"
2. Заполните форму регистрации:
   - Имя
   - Email
   - Пароль (минимум 6 символов)
   - Возраст (опционально)
3. Войдите в систему используя свои учетные данные

### Добавление растений

1. Перейдите в раздел "Каталог"
2. Используйте поиск или фильтры для поиска нужного растения
3. Нажмите "Добавить" на карточке растения
4. При желании введите название для растения

### Управление растениями

1. Перейдите в раздел "Мои растения"
2. Вы увидите статистику и список ваших растений
3. Для каждого растения доступны действия:
   - 💧 Полить - отметить полив
   - 🧪 Удобрить - отметить внесение удобрения
   - 🗑️ Удалить - удалить растение из коллекции

### Выполнение задач

1. На главной странице отображаются актуальные задачи
2. Задачи имеют индикаторы срочности:
   - 🔴 Срочно - требуется немедленное внимание
   - 🟡 Важно - выполнить в ближайшее время
   - 🟢 Планово - запланированная задача
3. Нажмите "Выполнено" для завершения задачи
4. Нажмите "Отложить" для переноса задачи на следующий день

## 🗄️ База данных

Приложение использует SQLite базу данных (`plantcare.db`), которая создается автоматически при первом запуске.

### Структура базы данных:

- **users** - данные пользователей
- **plant_catalog** - каталог растений
- **user_plants** - растения пользователей
- **tasks** - задачи по уходу
- **tips** - советы по уходу

### Предустановленные растения:

Приложение включает 10 популярных растений:
- Монстера
- Фикус
- Суккулент
- Сансевиерия
- Спатифиллум
- Плющ
- Алоэ
- Фикус каучуконосный
- Замиокулькас
- Хлорофитум

## 🐛 Устранение неполадок

### Приложение не запускается

1. Убедитесь, что установлен Python 3.8 или выше
2. Проверьте установку зависимостей: `pip install -r requirements.txt`
3. Убедитесь, что нет других процессов, использующих порт (если применимо)

### Ошибка базы данных

1. Удалите файл `plantcare.db`
2. Перезапустите приложение - база данных будет создана заново

### Проблемы с отображением интерфейса

1. Убедитесь, что установлена библиотека CustomTkinter
2. Попробуйте переустановить зависимости:
```bash
pip install --upgrade -r requirements.txt
```

## 🔒 Безопасность

- Пароли хранятся в базе данных в открытом виде (для демонстрационных целей)
- При реальном использовании рекомендуется добавить хеширование паролей
